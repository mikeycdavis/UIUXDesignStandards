## What

Plan section 11. A CI workflow of bare `npm run` steps with no install step, the four root documents,
the architecture description with its canonical diagram source, and doc-to-code bindings.

## Why

Documentation drift is invisible without bindings. A named command, envelope field, disposition, or
rule id has to resolve to the thing that would make the claim true.

## Notes

Writing the bindings found two real defects in prose that read perfectly well: a link to a filename
that does not exist, and a sentence naming an `npm run init` that deliberately does not exist. The
install-step guard also failed on the workflow comment explaining why there is no install step — the
third appearance of the use/mention shape.
